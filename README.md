# Iberochamber

Sitio web de **Ibero Chamber** — Cámara de Empresarios Iberoamericanos en los Estados Unidos.

Sitio estático (HTML, CSS y JS) basado en la plantilla Stadum. Cada página está en
su carpeta con un `index.html`, igual que las URLs del sitio anterior en WordPress.

- `index.html` — portada
- `assets/css/ibero.css` — estilos de la marca (se carga después de `style.css` de la plantilla)
- `assets/js/ibero.js` — JavaScript propio del sitio (después de `main.js` de la plantilla)
- `media/` — imágenes del contenido
- `mail.php` — envío del formulario de contacto (requiere hosting con PHP)
